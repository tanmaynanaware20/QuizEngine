# Quiz Engine 🎯

A simple and interactive quiz application built using **HTML, CSS, and JavaScript**.
The goal of this project was to create a clean and responsive quiz experience where users can test their knowledge with instant feedback.

---

## 🌐 Live Project

https://tanmaynanaware20.github.io/QuizEngine/

---

## 💡 About the Project

This project focuses on building a quiz system from scratch using core web technologies without any external frameworks.
It handles question rendering, user interaction, answer validation, and score tracking in a smooth flow.

The idea was to keep the structure simple while making the experience engaging and easy to use.

---

## ⚙️ What It Does

* Displays questions one by one
* Allows users to select answers
* Shows immediate feedback
* Keeps track of score
* Moves through the quiz in a structured flow

---

## 🛠 Tech Used

* HTML
* CSS
* JavaScript (Vanilla)
